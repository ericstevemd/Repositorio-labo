# Repositorio-Labo

Laboratorio de ciberseguridad de nivel **principiante** a nivel **profesional**. Aquí encontrarás material sobre máquinas y desafíos de plataformas como **TheHackLabs**, **Hack The Box** y otras páginas conocidas.

## Estructura

| Carpeta | Descripcion |
| --- | --- |
| `Principiante/` | Maquinas y laboratorios de nivel basico |
| `intermedio/` | Laboratorios de nivel intermedio |
| `avazado/` | Laboratorios de nivel avanzado |
| `Comando Rapido/` | Cheatsheets y comandos rapidos (NMAP, etc.) |

## Contenido

- Notas de maquinas resueltas por nivel de dificultad
- Guias de comandos rapidos (ej: NMAP)
- Documentacion de laboratorios de TheHackLabs, Hack The Box y mas

## Como usar

1. Navega a la carpeta segun tu nivel (`Principiante`, `intermedio`, `avazado`).
2. Revisa la nota de cada maquina.
3. Consulta `Comando Rapido/` para cheatsheets de herramientas.

## Contribuciones

Este repositorio esta en crecimiento. Si tienes material para compartir, agrega tus notas y subelas.
