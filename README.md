# Repositorio-Labo

Laboratorio de ciberseguridad, desde nivel **principiante** hasta nivel **profesional**. Aquí encontrarás material sobre máquinas y desafíos de plataformas como **The Hackers Lab**, **TryHackMe**, **Hack The Box** y otras páginas conocidas.

## Estructura

| Carpeta | Descripción |
| --- | --- |
| `Principiante/` | Máquinas y laboratorios de nivel básico |
| `intermedio/` | Laboratorios de nivel intermedio |
| `avazado/` | Laboratorios de nivel avanzado |
| `Comando Rapido/` | Cheatsheets y comandos rápidos (Nmap, etc.) |

## Contenido

- Notas de máquinas resueltas, ordenadas por nivel de dificultad
- Guías de comandos rápidos en `Comando Rapido/`
- Documentación de laboratorios de The Hackers Lab, TryHackMe, Hack The Box y más

### Comandos rápidos

| Archivo | Contenido |
| --- | --- |
| `Comando Rapido/Nmap.md` | Escaneo de puertos y scripts |
| `Comando Rapido/Enumeracion web.md` | gobuster, wfuzz, ffuf, whatweb, CeWL, `/etc/hosts` |
| `Comando Rapido/WordPress y wpscan.md` | Enumeración de usuarios, fuerza bruta y exploits de plugins |
| `Comando Rapido/SQLmap.md` | Inyección SQL, JWT/Bearer y volcado de bases de datos |
| `Comando Rapido/Fuerza bruta y crackeo.md` | hydra, John the Ripper, esteganografía |
| `Comando Rapido/SMB y Active Directory.md` | smbclient, netexec, Kerberos, LDAP, WinRM |
| `Comando Rapido/Shells y transferencia.md` | Reverse shells, msfvenom, FTP, RDP, subida de archivos |
| `Comando Rapido/Escalada de privilegios Linux.md` | sudo, GTFOBins, SUID, cron, PATH |
| `Comando Rapido/Escalada de privilegios Windows.md` | Privilegios, JuicyPotato, PetitPotam, servicios |

## Cómo usarlo

1. Navega a la carpeta según tu nivel (`Principiante`, `intermedio`, `avazado`).
2. Revisa la nota de cada máquina: reconocimiento, enumeración, explotación y escalada de privilegios, con los comandos y las capturas de cada paso.
3. Consulta `Comando Rapido/` para los cheatsheets de herramientas.
